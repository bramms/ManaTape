# Карта знань Mana Tape

Mana Tape — самостійний український пульт для підготовки конфігурацій OMP на Linux і macOS. Його мета — швидко зрозуміти доступний ресурс, зібрати послідовність виконавців і явно зберегти її для майбутніх запусків. Відчуття — один компактний музичний прилад: котушка, монтажна плівка, LCD, ручки й фізичні клавіші.

Проєкт не керує життєвим циклом робочих агентів і не прив’язаний до конкретних ролей, підписок чи зовнішнього проєкту. Це pet-проєкт: простий запуск, невеликий стек і зрозумілі гарантії важливіші за платформу розширень або складний процес управління знаннями.
